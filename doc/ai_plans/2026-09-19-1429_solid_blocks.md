# Implementation Plan: Solid Blocks & Decoupled Selections

## Goal
1. **Solid Blocks (ECS):** Implement unbreakable walls that have no numeric value and physically clamp drag selections.
2. **Decoupled Selection Engine:** Rewrite the left-click interaction so that the Box selection and the Diagonal selection compute completely independently and simultaneously, allowing one to clamp on a wall while the other stretches freely.

## Proposed Changes

### 1. Create the Solid Blocks Feature Slice
- **[NEW]** `src/features/solid-blocks/model/solidBlocksStore.ts`
  - Create a Zustand store: `walls: Record<string, boolean>`.
- **[NEW]** `src/features/solid-blocks/ui/WallRenderer.tsx`
  - Renders SVG walls on top of the tiles based on the store.
- **[NEW]** `src/features/solid-blocks/index.ts`

### 2. Connect Feature to Board Generation
- **[MODIFY]** `src/widgets/game-board/ui/GameBoardWidget.tsx`
  - Add a `useEffect` listening to `boardStore.seed` and `configStore.enableSolidBlocks` to randomly place walls.
  - Mount `<WallRenderer />`.

### 3. Decouple Box and Diagonal Selections
- **[MODIFY]** `src/features/select-tiles/model/selectionMath.ts`
  - Remove the `isSquare` dependency from the diagonal calculation in `calculateDetailedBoxSelection`.
  - On a left-click drag, mathematically compute the `boxTiles` AND calculate the full `diagonalTiles` independently (using the average distance logic currently used by right-click).
  
### 4. Apply Independent Clamping & Collisions
- **[MODIFY]** `src/widgets/game-board/model/GameBoardInteraction.ts`
  - Update `BoardContextAccess` to include `hasWall: (col: number, row: number) => boolean`.
  - **Box Clamping**: If the calculated Box contains a wall, clamp its width/height back to the largest valid rectangle before the wall, and set a `isBoxColliding = true` flag.
  - **Diagonal Clamping**: If the calculated Diagonal ray hits a wall, truncate the ray at the wall, and set a `isDiagColliding = true` flag.
  - **Simultaneous Evaluation**: Evaluate the clamped Box and clamped Diagonal independently. If either hits the target sum (10), it succeeds.
- **[MODIFY]** `src/widgets/game-board/model/GameBoardRenderer.ts`
  - If `isBoxColliding` is true, render the box outline in **Red**.
  - If `isDiagColliding` is true, render the diagonal ray in **Red**.
  - (If one is red but the other is valid and equals 10, the valid one remains golden/green).

## Verification Plan
1. Boot game, enable `enableSolidBlocks`.
2. Left-click drag. Verify the game draws BOTH a Box and a Diagonal Ray simultaneously.
3. Drag such that the Box hits a wall, but the Diagonal misses it. Verify the Box outline stops and turns Red, while the Diagonal Ray continues stretching cleanly.
4. Verify if the Diagonal Ray hits 10, it clears, ignoring the red clamped Box.
