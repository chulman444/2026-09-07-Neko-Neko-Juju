# Migrate DevHotkeys Feature

The `DevHotkeys` feature from the reference codebase provides a way to quickly mutate the board's digits by hovering over tiles and pressing number keys (or Backspace to clear, 'R' to randomize). This plan migrates the feature and extends it by making it toggleable via the Dev Tuner side panel.

## Proposed Changes

### features/dev-hotkeys

#### [NEW] `src/features/dev-hotkeys/model/devHotkeysStore.ts`
- A Zustand store to hold the toggle state for the hotkeys.
- State: `isDevHotkeysEnabled` (default: false)
- Action: `setDevHotkeysEnabled(enabled: boolean)`

#### [NEW] `src/features/dev-hotkeys/model/useDevHotkeys.ts`
- Adapts the legacy hook to the modern FSD architecture.
- Listens to `keydown` to mutate the board using `useBoardStore.getState().setTileValue(c, r, val)`.
- Listens to `pointermove` on the `window` to track the current `hoverTile` by calculating the cursor position relative to the `<canvas>` element's `getBoundingClientRect()`.
- Calculates grid coordinates using `shapeSize` and `tileBorder` from `useBoardStore`.
- Skips event binding entirely if `isDevHotkeysEnabled` is false.

#### [NEW] `src/features/dev-hotkeys/ui/DevHotkeys.tsx`
- A renderless component that executes `useDevHotkeys()`.
- Will be mounted inside the main `GamePage`.

#### [NEW] `src/features/dev-hotkeys/ui/DevHotkeysToggle.tsx`
- A UI component providing a toggle switch (or checkbox) that connects to `devHotkeysStore`.

#### [NEW] `src/features/dev-hotkeys/index.ts`
- Public API exposing `DevHotkeys` and `DevHotkeysToggle`.

## Verification Plan

### Manual Verification
1. Open the game.
2. Verify that hovering over tiles and pressing numbers `1-9` does **not** mutate the board initially.
3. Open the Dev Tools side panel.
4. Toggle "Dev Hotkeys" on.
5. Hover over a tile and press a number key (e.g., `5`). Ensure the tile digit changes to 5.
6. Press `Backspace` to ensure the tile clears to 0.
7. Press `R` to ensure the tile gets randomized.
8. Verify that turning off the toggle disables the hotkeys again.
